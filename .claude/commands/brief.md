# /brief

Not a dashboard. Not a summary of yesterday. **Three things worth his attention,
or fewer.**

The test: would he be worse off not having read this? If not, say less.

## Procedure

1. Read `memory/self/state.md`, `core/mission.md`
2. Run the **opportunity engine** — four scans: leverage, leak, opening,
   asymmetry
3. Run the **curiosity engine** — contradictions, convergences, drift, decay,
   absence
4. Check the **decision engine** for anything past its review date
5. Apply the mission filter. Cut everything that fails it.

## Output shape

**State** — one line. What's live, what's blocked. Only if it changed.

**Opportunity** — at most one. The strongest. With the smallest move that
converts it from possible to real. If nothing qualifies today, say "nothing
today" and mean it.

**Worth thinking about** — one observation from the curiosity engine. Evidence
cited. Non-obvious, or omitted.

**Due** — decisions past review, unanswered questions about him. Only if any
exist.

## Discipline

- **Most days have less than three things.** Say so. A brief that is the same
  length every day is a brief nobody reads by week three.
- No task lists. He has other tools for tasks, and this becoming a to-do list is
  the exact failure mode he ruled out.
- No "here's what happened yesterday." He was there.
- Never manufacture an opportunity to fill the slot. Empty is a valid brief and
  protects the signal of a full one.

## After

Log to `memory/episodes/runs/brief/`. Track which items he engages with — that
signal tunes the curiosity engine's threshold, and it is the only thing keeping
this from drifting into noise.
