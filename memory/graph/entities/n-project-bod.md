across many versions since at least early June 2026. Works with Pardita on it.

## What the artifacts show

- Repeated versioned builds shipped as archives — a real iterative process, not
  a one-shot
- Variants **with and without a 3D bottle**, kept as parallel versions rather
  than one replacing the other
- A separate tracker, versioned to v3
- Built across harnesses, moved between tools mid-project

## Why this is the most valuable unmined thing in the graph

Every version pair is a **taste decision with a rationale attached**. He chose
to keep a 3D-bottle variant and a plain variant side by side — that choice, and
whichever he shipped, is exactly the kind of evidence the taste engine has none
of.

The taste profile currently reads zero across every craft dimension while this
project sits there containing months of his actual design judgments.
