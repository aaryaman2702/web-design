# Engineering

The trajectory: use AI → build with AI → build AI systems → design agent
architectures others adopt.

Currently between the second and third. The distinguishing skill is not calling
models — it is memory architecture, evaluation, and reasoning correctly about
failure modes before they occur.

**Instrument:** JARVIS itself. Maintaining it, extending it under contract, and
diagnosing it when it misbehaves teaches this more directly than any course,
because the feedback is real and the failures are his own.
